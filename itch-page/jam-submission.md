# GMTK Game Jam 2026 Submission

## How does the game fit the theme "COUNT DOWN"?

Every attempt runs against a visible countdown. When it reaches zero—or the player ends the run early—the recorded path becomes a ghost while the clock starts again. Progress comes from arranging those short, expiring timelines so past selves can hold switches, open routes, and even freeze into platforms for the current one.
